### RVN: Why the hash is there

The last few days the stories run together.

Replies that stop where the numbers become uncomfortable.

It is not a new phenomenon.  
It is just visible.

### What the Open Internet Manifest does

The site is open source. The code is on GitHub.  
Anyone can see what is running.

Every post has a SHA-256.  
On the full text and on the clean text (without formatting).  
The hash changes if one character changes.  
No “trust us”. Just: check it yourself.

The theses are there.  
The guides.  
The concepts that need to stay sharp — like in the series on [stretching](https://openinternetmanifest.org/social-posts/en/day-154-rvn.html) of words.  
What is still coming will be added. Open.

### The point

A platform that is only a shop window can adjust the story.  
A black box can run filters you do not see.  
A text without a hash is a claim.

The last few days show what happens when the record is not fixed.  
Words get stretched. Images get framed. The other side is not mentioned.

The Open Internet Manifest is not an opinion.  
It is a method: open code, fixed hash, clean text, checkable post.

Not because everyone has to agree.  
But because the text that is there is the text that was there.
